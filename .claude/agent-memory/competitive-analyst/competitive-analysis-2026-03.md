## Key Differentiators by Competitor

### Senja
- Strongest direct competitor
- Shadow DOM embed (same as Vouch)
- Import from 30+ platforms
- Sentiment analysis, auto-translation
- Rich snippets SEO
- Spin the Wheel engagement feature
- G2 rating: 8.8

### Testimonial.to
- iframe-based embed (iframeResizer)
- Video editing/trimming/captions
- Limited import (17 sources)
- $30/space for additional projects
- Chrome extension for social import

### EmbedSocial
- Broader platform (social feeds, reviews, UGC)
- AI-powered features
- 300K+ users (largest user base)
- View-based pricing model
- Not testimonial-focused

### Endorsal
- Automated review collection (email + SMS)
- Usage-based pricing (contacts + visitors)
- Google/Facebook/Yelp import
- FOMO popups
- Most expensive entry point

### Shoutout.io
- Video-first approach
- Auto-generated animated videos from text
- Storage-based pricing
- Appears less actively maintained (last updates 2023)
