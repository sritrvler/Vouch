# Product Decision Gate

TRIGGERS when about to: add features to roadmap, write comparison copy, change pricing, design user flows, write marketing copy, evaluate competitors, or make strategic recommendations.

Does NOT trigger for: bug fixes, CSS, refactoring, infrastructure.

## The 5 Checks (answer each with one specific sentence)

```
PRODUCT DECISION GATE:
[ ] 80/20: Does 20%+ of target audience use this daily? Evidence?
[ ] HONEST COMPARISON: Leading with genuine strengths, or cherry-picking?
[ ] VALIDATED PAIN POINT: Real users reported this, or assumed? Source?
[ ] LIVE DATA: Competitor claims from live exploration, or pricing pages?
[ ] GROWTH ENGINE: Helps free users succeed (badge impressions)?
```

Say `PRODUCT DECISION GATE PASSED` after completing all 5.

If any check fails: stop, flag to user, do not proceed.
