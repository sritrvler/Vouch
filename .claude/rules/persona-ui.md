# Persona-Driven UI Design

Every UI decision serves a specific human on a specific device. No defaulting.

## For EVERY UI component choice, write per affected persona:

```
Persona: [Name] ([role], [plan])
Device: [screen size, input method]
Context: [where they are, what they just did]
Task: [next 60 seconds]
Feel: [how this should feel to THEM]
```

## Business Impact (evaluate alongside persona, not after):

1. Retention: Does this make the product stickier?
2. Conversion: Free-to-paid boundary natural or punishing?
3. Time to value: Steps from signup to "aha moment"?
4. Churn risk: What could confuse or frustrate?
5. Expansion: Exposes higher-tier features naturally?
6. Referral: Natural place for sharing/visibility?

## Red Flags (you defaulted instead of designed):

1. "Matches existing pattern" without evaluating per persona
2. "Standard approach" without asking "standard for whom?"
3. Picked UI before writing persona intents
4. Business impact says "supports retention" without explaining HOW
